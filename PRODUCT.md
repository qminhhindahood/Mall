# Mall visitor guides

## Platform

Web. Two independent, bilingual Astro sites with React interaction and lazy Three.js scenes, built from one shared implementation.

## Users and purpose

Visitors to Saigon Centre (including Takashimaya and surrounding tenants) and Vincom Center Đồng Khởi can explore the building, find destinations and inspect reviewed walking connections. Vietnamese and English have equivalent journeys on desktop and phone.

## Confirmed constraints

The owner's 21 October redesign request separates Home introductions from full-page Discovery and Directions. Home retains the actual exterior, direct rotate/look/zoom/reset controls and interruptible arrival. Discovery begins with real directory highlights, then complete search and category/floor browsing. Directions preserves the combined glass origin/destination card and existing maps. Existing legacy and direct destination links remain supported.

Only supplied building assets, directory records, source plans and reviewed route connections are used. Area associations never imply exact doors or universal routing. Partial/shared areas, Opening Soon records and unverified metadata keep their qualifications. Model failure and reduced motion cannot block practical tasks.

## Delivery boundary

This is an isolated, unpublished candidate. Mapping/routing data, approved source assets and canonical worktrees are outside this visual redesign. Private cloud migration and publication remain separate tasks.
